# Gate report: M3 — Non-bonded pair interactions

## What was built
The team implemented non-bonded pair interactions for `ucmd-ff`, covering Lennard-Jones 12-6 pairs, Coulomb pairs, combination rules, bond-graph exclusions, and both non-periodic and periodic evaluations.

## Evidence
- **R3.1**: Covered by `lj_pair` (energy, force, virial), `combination_rule` (geometric and Lorentz-Berthelot sigma/eps rules), and `coulomb_pair`.
- **R3.2**: Covered by `coulomb_pair`, which uses the project constant `COULOMB_KJ_MOL_NM_E2`.
- **R3.3**: Covered by `exclusions` and `pair_class_map`, which classify pairs as Excluded (path 1-2), OneFour (path 3), or Normal based on BFS shortest-path.
- **R3.4**: Covered by `nonbonded_nonperiodic`, which returns split LJ/Coulomb energy, forces, and virial for all valid pairs.
- **R3.5**: Covered by `minimum_image`, `min_image_disp`, and `nonbonded_periodic`. Validation includes Rahman-1964 argon parameters, finite-difference checks, and force summation.

## Deviations and open issues
- **Test Corrections**: Multiple tests were corrected after referee rulings. `lj_pair` tolerance adjusted to 1e-14; `coulomb_pair` removed incorrect off-diagonal virial assertions; `nonbonded_nonperiodic` fixed to use a 4-atom chain for 1-4 scaling; `min_image_disp` corrected triclinic expected values; `nonbonded_periodic` adjusted cutoffs (0.49, 0.9), positions, and cell sizes to satisfy strict inequality and avoid boundary artifacts.
- **Open Review Remark**: `nonbonded_periodic` has an open remark: change cutoff validation from `>` to `>=` to enforce strictly less than half the minimum perpendicular height.
- **Superseded Requests**: Change requests for `fd_test` and `ryckaert_bellemans_dihedral` were superseded by overseer routing fixes.

## Questions for the author
1. Should the open review remark on `nonbonded_periodic` (cutoff validation operator) be resolved before closing the gate?
2. Are the Rahman-1964 argon parameters (sigma = 0.34 nm, eps/k_B = 120 K) confirmed as pre-approved for all M3 tests?
