# Gate report: M1 — Foundations and harmonic bonded terms

## What was built
The team implemented the foundational modules and harmonic bonded terms for `ucmd-ff`. The build system reports 47 passing tests with 0 failures across seven modules: `constants`, `vec3`, `errors`, `cell`, `bond`, `angle`, and `fd_test`. All modules adhere to the project rules, including the use of `f64`, Rust without external crates, and proper error propagation.

## Evidence
- **R1.1 (Constants):** Module `constants` covers this requirement. 6 tests pass. The module defines CODATA 2018 values and derived gas/Coulomb constants. Tests verify values against tabulated references to 1e-12 relative tolerance.
- **R1.2 (Vector helpers):** Module `vec3` covers this requirement. 7 tests pass. It provides add, subtract, scale, dot, cross, and norm operations on `[f64; 3]`.
- **R1.3 (Error type):** Module `errors` covers this requirement. 6 tests pass. It defines the library error enum for invalid inputs (non-finite, coincident atoms, index out of range, invalid cell).
- **R1.4 (Periodic cell):** Module `cell` covers this requirement. 8 tests pass. It implements validity checks, volume calculation, and minimum-image displacement. Tests compare minimum image against a brute-force search over 27 neighboring images.
- **R1.5 (Harmonic bond):** Module `bond` covers this requirement. 7 tests pass. It computes energy, forces, and virial for harmonic bonds.
- **R1.6 (Harmonic angle):** Module `angle` covers this requirement. 7 tests pass. It computes energy, forces, and virial for harmonic angles, with explicit error handling for degenerate geometries.
- **R1.7 (Finite-difference kit):** Module `fd_test` covers this requirement. 6 tests pass. It provides central difference force checks and strain-based virial checks for subsequent modules.

## Deviations and open issues
- **Test changes:** None. No tests were changed after the test referee ruled them wrong.
- **Module amendments:** Module `errors` was amended additively to implement `Debug` (and `Clone`, `PartialEq`) at the request of `bond` to satisfy compiler requirements. This change is guarded by existing tests.
- **Uncovered requirements:** None. All requirements R1.1 through R1.7 are covered by passing tests.
- **Failed modules:** None. All modules passed on their first or second attempt (only `angle` required one repair round).

## Questions for the author
1. The evidence notes that `fd_test` uses function pointers. Is this the intended design for the finite-difference kit, or should it use closures/traits for better composability in later milestones?
2. The `cell` module initially missed four specific sign/index errors in the minimum-image calculation. Has the brute-force comparison test been strengthened to cover all 27 images explicitly, or does it rely on random sampling?
